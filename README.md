### 🎯 Project Objective

91% of cyber attacks start with a phishing email. This project aims to train non-technical users to recognize fake emails, fake websites, and social engineering tactics through practical examples and an interactive quiz.

This project was built as Task 2 for the CodeAlpha Cyber Security Internship.

### ✨ Key Features

#### 1. Comprehensive Learning Modules
- **What is Phishing?** - Types: Email Phishing, Spear Phishing, Whaling, Smishing, Vishing
- **Red Flags** - How to spot a fake email (Sender mismatch, Urgency, Generic greeting)
- **Fake Websites** - URL analysis, Look-alike domains (micros0ft, paypaI)
- **Social Engineering** - Tactics like Authority, Fear, Greed, Curiosity
- **Best Practices** - Stop-Think-Click, 2FA, Password Manager

#### 2. Real-World Examples
- LinkedIn Job Offer Scam (2023)
- Google Docs OAuth Scam
- Pakistan Banking SMS Scams (Easypaisa / JazzCash)

#### 3. Interactive Quiz System
- 5 scenario-based questions
- Instant feedback with explanation
- Progress bar and final score
- Retake functionality

#### 4. Practice Labs Integration
- Reference to real-world platforms like PhishTank.org (Cisco Talos) and Google Phishing Quiz by Jigsaw

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Design:** Responsive Grid, Modern UI with CSS Variables
- **Hosting:** GitHub Pages / Vercel
- **No external libraries** - Pure HTML/CSS/JS for fast loading
